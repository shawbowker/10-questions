# \# 10 questions

Generate 10 random questions



\##Features:

1. Generates 10 random questions.
2. Each question has 4 different options.
3. Can choose a category all the questions will be based on or by default each question will randomly generate the category.
4. Can choose a difficulty of Easy, Medium or Hard. No difficulty chosen randomises each questions difficulty.
5. Immediately tells you if the answer is correct and if it's wrong it tells you the correct answer.
6. Shows your score at the end and allows you to start again.



\##Technologies Used:

1. HTML
2. CSS
3. JavaScript
4. Open Trivia Database API
